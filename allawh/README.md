# اللوح المحاور — بوابة مجانية

هذه النسخة لا تتصل بخدمة Supabase ولا تطلب اشتراكًا أو دفعًا أو رمز تفعيل. أزيل تتبع الزيارات والمتصلين. بيانات الطالب والتقدم تحفظ محليًا في المتصفح.

روابط الكتب والفهارس الخارجية ما زالت تقود إلى مواقعها الأصلية. ملفات الكتب ومفاتيح الدروس المشفرة ليست ضمن هذا المشروع؛ تغيير البوابة لا يغير صلاحيات الوصول في تلك المواقع.
