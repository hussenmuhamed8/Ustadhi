# اللوح المحاور — نسخة ويب ثابتة

نسخة ثابتة من واجهة البوابة الرئيسية للوح المحاور. الواجهة عربية وتحتفظ بالهوية والتفاعلات المنشورة. صفحات الكتب المنفصلة ومحتواها غير منسوخة؛ تظل روابط البوابة متجهة إلى مواقعها الأصلية. كما لا تنشئ هذه النسخة خادمًا أو قاعدة بيانات. عدادات الزيارات والميزات المرتبطة بخدمات خارجية تستخدم إعداداتها الحالية وقد تعتمد على سماح الخدمة للنطاق الجديد.

ملفات النشر موجودة في `public/`. المشروع يستخدم بناءً ثابتًا بلا حزم أو خطوة تجميع؛ يتطلب التطوير المحلي تشغيل خادم HTTP من جذر المشروع، مثل `python3 -m http.server 8000 --directory public`.
